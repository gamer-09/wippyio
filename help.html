How to use storage-packed and wippy together.

← Back to Portfolio

overview How It All Works

There are two repos that work together:

  • storage-packed — A local web app that stores your project archives in a browser vault. This runs on your machine only.
  • wippyio — A static website hosted on GitHub Pages that displays all your projects as a public portfolio.

🚀 Step-by-Step Workflow

1

Start storage-packed

Open a terminal and run the storage-packed server locally:

cd storage-packed
npm install # first time only
npm start

It will print a local URL (usually http://localhost:3000). Open it in your browser.

2

Upload your projects

In the storage-packed browser vault:

  • Upload a folder — Click "Upload a project" and select a project folder. It stores all the files locally in data/projects/.
  • Add a summary — Use the Gemini AI button (paste your API key) or create a local draft summary to describe the project.
  • Mark completion — Toggle whether the project is completed or still in progress.
  • Edit if needed — You can edit summaries, completion status, and other details from the card or popup.

💡 Tip: You don't need to push storage-packed to GitHub. The data/ folder is gitignored — it only lives on your machine.

3

Sync to wippyio

After adding or updating projects, run the sync from the wippyio directory:

cd wippyio
node sync-projects.js

This reads storage-packed/data/projects.json, detects GitHub repos from stored files, and writes a slim version to wippyio/data/projects.json.

You'll see output like:

📖 Reading .../storage-packed/data/projects.json
✅ Wrote 32 projects to data/projects.json
17950 KB → 78 KB (100% smaller)
12 project(s) with GitHub repos detected

💡 Tip: If the repos are in different folders, pass the path: node sync-projects.js /full/path/to/storage-packed

4

Push to GitHub

Commit and push the updated data to GitHub:

git add data/projects.json
git commit -m "Update project portfolio data"
git push

Or use the one-command script:

./update.sh

GitHub Actions will automatically deploy the updated site to https://gamer-09.github.io/wippyio/.

⌨️ Quick Reference

# Start the vault (to add/edit projects)
cd storage-packed && npm start

# Sync projects to wippyio
cd wippyio && node sync-projects.js

# One-command sync + push
cd wippyio && ./update.sh

# Sync from a different path
node sync-projects.js /other/path/to/storage-packed

❓ FAQ

Q: Do I need to keep storage-packed running for the portfolio to work?

No. The portfolio is a static site — once synced and pushed, it works on its own. storage-packed only needs to be running when you want to add or edit projects.

Q: How often should I sync?

Whenever you add or update a project in storage-packed. There's no automatic sync — you run the script manually (or use ./update.sh for a one-command sync + push).

Q: What if I don't have Node.js?

The sync script requires Node.js to run. Install it from nodejs.org. You don't need Node.js for the portfolio site itself — that's just static HTML/CSS/JS.

Q: Where does the project data come from?

From storage-packed/data/projects.json — the same database that powers the storage-packed vault. The sync script reads it directly from your local disk.

⚠️ Important: The data/ folder in storage-packed is gitignored. Do not try to push storage-packed to GitHub expecting the data to be there — it won't be. The sync reads from your local machine only.

Q: Can I edit the slimmed data directly?

You can, but it will be overwritten the next time you run the sync. Always make changes in storage-packed, then re-sync.

Q: How does GitHub repo detection work?

The sync script scans each stored project's files for .git/config, package.json, and README/markdown files to find GitHub URLs. If found, a link icon appears on the project card.

🎨 Site Features

  • 3 views — Grid (cards), List (compact rows), and Timeline (vertical timeline by date)
  • Search — Type in the search box to filter by project name, summary, languages, or GitHub URL
  • Filters — Show All, Completed, or In Progress projects
  • Sort — Newest, Oldest, Name A→Z, Name Z→A, Largest, Smallest
  • Dark/Light theme — Click the sun/moon button in the top right. Your choice is remembered.
  • Project details — Click any project card to see the full summary, languages, file types, and GitHub link
  • GitHub links — Projects with detected repos show a GitHub icon linking directly to the repo
  • Animated stats — The header shows animated counters for total, completed, in-progress, and languages
  • Responsive — Works on mobile, tablet, and desktop
