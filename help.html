How to use storage-packed and wippy together.

There are two repos that work together:

  • storage-packed — A local web app that stores your project archives in a browser vault. Runs on your machine only.
  • wippyio — A static website on GitHub Pages that displays all your projects as a public portfolio.

🚀 Step-by-Step Workflow

1

Start storage-packed

Open a terminal and run the storage-packed server locally:

cd storage-packed
npm install # first time only
npm start

It will print a local URL (usually http://localhost:3000). Open it in your browser.

2

Upload your projects

In the storage-packed browser vault:

  • Upload a folder — Click "Upload a project" and select a project folder.
  • Add a summary — Use the Gemini AI button or create a local draft summary.
  • Mark completion — Toggle whether the project is completed or in progress.
  • Edit if needed — Edit summaries, completion status, and other details.

💡 Tip: You don't need to push storage-packed to GitHub. The data/ folder is gitignored — it only lives on your machine.

3

Sync to wippyio

After adding or updating projects, run the sync:

cd wippyio
node sync-projects.js

This reads storage-packed/data/projects.json, detects GitHub repos, checks visibility, and writes a slim version.

💡 Tip: Add --screenshots to capture project screenshots: node sync-projects.js --screenshots

4

Push to GitHub

Commit and push the updated data:

git add -A
git commit -m "Update project data"
git push

Or use the one-command script:

./update.sh

GitHub Actions deploys automatically to https://gamer-09.github.io/wippyio/

❓ FAQ

Q: Do I need storage-packed running for the portfolio to work?

No. The portfolio is a static site — once synced and pushed, it works on its own.

Q: How often should I sync?

Whenever you add or update a project. Run the script manually or use ./update.sh for one-command sync + push.

Q: How do screenshots work?

The sync script uses your system Chrome (via puppeteer-core) to screenshot each project's web page. Projects without web content get gradient fallback cards with emojis.

Q: What do the badges on cards mean?

🌐 Public / 🔒 Private — repo visibility from GitHub API. ✨ Updated — project was modified after creation.

⚠️ Important: The data/ folder in storage-packed is gitignored. The sync reads from your local machine only.

Q: How does GitHub repo detection work?

The sync scans each project's files for .git/config, package.json, and markdown files to find GitHub URLs.
